Three ways to make GlideDeck look current

A proposal for the editor and the welcome deck. Each direction below is a mockup of the same screen: the editor open on a new welcome canvas. Pick one, or mix a shell from one with a deck from another.

1 · Daylight2 · Darkroom3 · FlightpathPlan

What makes today's app read as old

  • The Office ribbonAbout 150px of grouped commands labelled Clipboard, History and Arrange, most of them greyed out at rest. It is the 2007 PowerPoint pattern, and it is the first thing a new user sees.
  • Boxes inside boxesThree docked panels, then cards inside the Properties panel, then a permanent Tips card. The canvas, which is the product, gets what is left.
  • Indigo accent on the system fontViolet buttons with Segoe UI is the default look of a generic app. Nothing in the chrome says GlideDeck.
  • The welcome deck's aurora lookStarfield dots, translucent gradient orbs, frosted cards, a pill badge and a tilted sticker. That style peaked around 2021.
  • The welcome deck is smallAt the overview the title fills about a sixth of the canvas width and the four feature cards cannot be read. The first frame should already impress.
  • The camera path is hiddenThe one thing competitors do not have is shown as a PowerPoint-style slide list. The moves between stops are invisible until you open a tab.

The welcome deck at its overview stop

What changes

One 52px toolbar replaces the ribbon. Design, Animate and Slide move into tabs on the right panel, so nothing is lost. Cobalt replaces violet. A bundled UI typeface replaces Segoe UI.

The welcome deck

Paper ground, a headline that fills half the canvas, four flat colour slabs along a dotted flight path. No gradients, glass or starfield. The portal is three solid circles.

Cost and risk

Lowest. The panel layout in app.rs stays; ribbon.rs is rewritten as a toolbar and the tab contents move into inspector.rs. Existing users find everything where they expect it.

The welcome deck at its overview stop

What changes

No ribbon and no docked panels. A tool dock sits at the bottom, a filmstrip on the left, and the inspector appears only when something is selected, with a small bar above the selection for the common edits.

The welcome deck

The wordmark runs the full width of the canvas, so the overview reads as a poster. Feature slabs are solid graphite, bone and yellow. The yellow disc is the zoom portal.

Cost and risk

Medium. Floating panels need hit-testing against the canvas and a rule for small windows. Menus that lived in the ribbon need a home, most likely a command search. It is the biggest visible change.

6 · Portal

The welcome deck at its overview stop

What changes

A vertical tool rail, a command search in the title bar, and a path timeline where each move shows its style and length and can be edited in place. The slide list and the Transitions tab merge into it.

The welcome deck

A transit-map route in one colour, with a stop per feature. It teaches the product's idea, that a talk is a journey, before the user clicks anything.

Cost and risk

Highest. The timeline is a new component with drag-to-reorder, and it changes how people navigate slides. It is also the only direction a competitor cannot copy by reskinning.

Recommendation

Ship Darkroom's look and canvas-first shell, with Daylight as its light mode, and add Flightpath's timeline later. The app already has a light and dark switch, so directions 1 and 2 can be the same design system in two palettes. That gives the fastest visible change without betting the release on a new component.

The quickest win is independent of the shell: a new welcome deck, a new accent and a bundled typeface change every screenshot and the first thirty seconds of use, and they touch only theme.rs, demo.rs and the theme list in glide-core.

Emergency plan

Days 1 to 3 · release 0.2.0

New face

  • New palette, radii and spacing tokens in theme.rs
  • Bundle one UI typeface instead of reading Segoe UI
  • Rebuild the welcome deck in demo.rs and examples/demo.glide.json
  • Two new default themes; retire the aurora gradients from the top of the gallery
  • New README screenshots
Week 1 to 2 · release 0.3.0

New shell

  • Replace the ribbon with the toolbar or dock
  • Move Design, Animate and Transitions into the inspector
  • Inspector shows only what the selection needs; Tips card removed
  • Press, hover and panel motion at 120 to 200ms
  • Update the UI snapshot tests and the tab names in the docs and the AI skill
Week 3 · release 0.4.0

Templates

  • Restyle the 18 templates on the new themes
  • Larger template picker with live previews
  • Start screen: recent files, templates, Import PowerPoint
Week 4 onward

Path timeline

  • Stops and moves on one strip
  • Command search for every action
  • Web page export picks up the new themes
