GlideDeck revamp, unified

One proposal built from your choices: the Flightpath layout, the Darkroom welcome deck, and an app theme the user can switch between dark and light.

  • Layout from FlightpathTools on the left, details on the right, the slide path along the bottom. The layout is identical in both themes.
  • Dark theme from FlightpathNavy panels with an aqua accent.
  • Light theme from DaylightWhite panels on cool grey with a cobalt accent.
  • Welcome deck from DarkroomGraphite canvas, full-width wordmark, one signal yellow.

The editor

Use the switch, or the half-circle button in the mockup's top bar, to see the other theme.

Left: tools

Select and Hand, then everything you can add: slide, text, shape, picture, icon, video. Templates sits at the bottom of the rail.

Right: details

Three tabs. Slide holds the camera move, builds and notes for the current stop. Design holds themes, background and Arrange. Animate holds the build list. With an object selected, the panel shows that object's properties.

Bottom: the path

Every stop as a thumbnail, and between each pair the move that connects them, with its style and length. Click a move to change it, drag a stop to reorder.

What "Search or run a command" is

Yes: the user types a few letters and picks a command from the list, without hunting through menus. Ctrl+K opens it from anywhere. It also finds slides by their text.

Why it is there

The ribbon showed every command at once. This layout shows only what the current task needs, so the rest needs one fast way in. Figma, VS Code and Notion use the same pattern.

It is optional

Nothing depends on it. File, Edit and View menus sit beside the deck name and hold every command, so a user who never types still finds everything.

If you would rather not have it

It can be left out of the first release. The top bar then shows the deck name in the centre instead.

The welcome deck

The Darkroom deck, unchanged. A deck keeps its own colours, so it looks the same whether the app around it is dark or light.

Dark and light

The app already has a theme button, so this replaces its two palettes and keeps the behaviour.

How the user chooses

The half-circle button in the top bar, View in the menu, or the command search. The choice is remembered between sessions.

What differs

Only colour. Dark is navy with aqua, light is white on cool grey with cobalt. Sizes, positions and icons are the same.

One thing to confirm

The two themes have different accent colours, as you asked. If you would rather have one brand colour in both, say which and I will use it for both.

Where the ribbon's commands go

The ribbon is removed. Nothing it held is dropped.
